Part 1

Prepare your system

The local command detects the selected stack. Missing tooling is shown as an installation plan before anything changes.

sh scripts/install.sh --dry-run --target single-host --engine docker
  • Docker, Podman, kubectl, Helm, Ansible and Argo CD CLI are checked only when selected.
  • Mutations require approval. There is no silent sudo, firewall, DNS or Kubernetes-context change.
  • K3s is an evaluation-only smoke-test profile. Production requires an approved existing cluster.
